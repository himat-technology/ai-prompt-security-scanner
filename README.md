## 🏗️ Architecture

```text
src/lib/security-scanner/
  index.ts              # 🎯 scanPrompt(), audit exporters
  types.ts              # 🧩 shared types
  scorer.ts             # 📊 weighted risk scoring
  sanitizer.ts          # 🛡️ deterministic hardening
  presets.ts            # 🧪 safe attack samples
  rules/
    prompt-injection.ts     # 🔴 Direct injection
    jailbreak.ts            # 🟠 Jailbreaks / DAN
    system-extraction.ts    # 🟡 System prompt leaks
    secrets.ts              # 🟢 API keys / tokens
    pii.ts                  # 🔵 Personal data
    exfiltration.ts         # 🟣 Markdown / webhooks
    obfuscation.ts          # ⚫ Zero-width / encoding
    indirect-injection.ts   # 🟤 MCP / tool context
```

## 🔐 Privacy

| ✅ Guarantee | 💬 Detail |
| --- | --- |
| 🖥️ **Local only** | Scanning runs in the browser (or local Node unit tests) |
| 🚫 **No scan network** | No `fetch` / XHR on the scan path |
| 🫥 **Redacted exports** | Secrets are redacted in UI + reports |
| 🧹 **No storage leaks** | Prompt text is not written to `localStorage`, URL params, or analytics |

---

## ⚠️ Limitations

Pattern-based detection can produce **false positives** and will not catch every novel attack. Treat results as a review aid — **not** a compliance certification.
